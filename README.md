# orkiestra-pytania
Strona stworzona dla członków orkiestry, szczególnie nowych osób. Umożliwia anonimowe zadawanie pytań dotyczących orkiestry, występów, mundurów, wyjazdów i innych spraw, bez obawy przed wstydem czy oceną. Członkowie mogą również dodawać wydarzenia, odpowiadać na pytania innych oraz oceniać najbardziej pomocne odpowiedzi. Wszystko w jednym miejscu!
